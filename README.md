# 瞑想リマインダー Chrome 拡張機能

ブラウザ起動から一定時間毎に瞑想を促す Chrome 拡張機能です。

## 機能

- ⏰ カスタマイズ可能なリマインド間隔（15 分〜2 時間）
- 🧘 設定可能な瞑想時間（1〜30 分）
- 🔔 控えめな通知音（開始時・完了時）
- 🎨 落ち着いたダークテーマ UI

## インストール

1. Code → Download ZIP
2. ダウンロードしたZIP(meiso-reminder-main.zip)を解凍
3. Chrome で `chrome://extensions/` を開く
4. 「デベロッパーモード」を ON
5. 「パッケージ化されていない拡張機能を読み込む」でフォルダ(meiso-reminder-main)を選択

## 使い方

- **設定**: ツールバーのアイコンをクリック → スライダーで調整 → 「設定を保存」
- **即座に開始**: 「今すぐ瞑想を開始」ボタン
